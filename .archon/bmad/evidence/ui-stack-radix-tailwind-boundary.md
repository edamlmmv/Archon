# UI Stack Radix and Tailwind Boundary

## Radix

Radix is used through Archon's shadcn-compatible primitives and upstream Radix accessibility contracts. No official Radix MCP server is claimed here.

## Tailwind

Tailwind is used through Tailwind v4 CSS-first theme variables in `packages/ui-lab/src/styles.css`. No official Tailwind MCP server is claimed here.

## Blocked Claims

- Do not claim `radix-mcp` support unless an official Radix MCP exists and is verified.
- Do not claim `tailwind-mcp` support unless an official Tailwind MCP exists and is verified.
- Use Storybook manifests, shadcn registry metadata, browser tests, and official docs evidence as the fallback route.
